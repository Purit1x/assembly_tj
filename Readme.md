​	项目源程序文件名：time_tsr.asm

​	源程序汇编与链接方式：

```bash
masm time_tsr.asm;
link time_tsr.obj;
```

​	程序功能：利用时钟中断，在后台判断，若已到某日某时某分，则在屏幕上输出一条消息

​	使用说明：在.asm文件中修改指定时间和要输出的消息后, 运行time_tsr.exe即可. 

​	主要技术：使用10h、1Ah的BIOS中断来在TSR的常驻部分打印消息，手动获取定时器中断1Ch原来的中断向量并保存，将自定义的新ISR链在原中断服务之后，实现预计功能。在输出完成后，程序将恢复中断向量并终止，返回到DOS。

​	值得改进的地方：

1. 打印消息可以定义一个字符串，对其循环遍历来打印消息，而非在代码中进行硬编码。

​	项目经验：

1. 在TSR的常驻程序部分，不能调用不可重入的中断，像int 21h的09h号功能和2A、2C功能均不应该被使用，而应该使用BIOS提供的int 10h和int 1Ah。
2. 在条件跳转语句被汇编器报错超出跳转范围时，可以将条件跳转语句替换为与原来的条件相反的条件跳转语句，并在其后添加一个near_label, 在near_label和条件跳转语句之间添加一个无条件跳转jmp到原来要跳转到的地方。
3. 在常驻部分程序中反复使用某一段重复代码时，若使用过程调用可能会有较大的额外开销，这时可以使用宏。
